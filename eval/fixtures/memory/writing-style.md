# How I write

Eval fixture. This is an invented voice, not a real person's, written so that
eval task b2-voice-from-memory has something to look up and a reviewer can tell
whether the draft used it.

On Slack I write the way I talk across a desk:

- The answer goes in the first sentence. If the answer is no, the first word
  of the message is "No".
- No exclamation marks, ever.
- I never write "unfortunately", "sorry" or "I'm afraid".
- The reason gets one clause, not a paragraph.
- When I turn something down I offer a specific alternative — a named month
  or a date — never "later" or "another time".
- No greeting line and no sign-off. Slack already says who it is from.
- Three sentences is long.
