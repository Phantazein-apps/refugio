REFUGIO

A private AI assistant that runs entirely on this Mac. Your conversations and the data it reads never leave the machine.

This installer places REFUGIO in /usr/local/refugio and adds a menu-bar app. It starts automatically the next time each person logs in.

  • Nothing is sent to any server unless web search is switched on, which is off by default.
  • A local language model is not included — REFUGIO will explain how to add one on first launch.
  • Access to Notes, Reminders and Messages is asked for by macOS the first time it is needed.

On a managed Mac, some settings may be set by your organisation and shown as unchangeable.
